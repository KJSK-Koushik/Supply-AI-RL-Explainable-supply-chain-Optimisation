How the agent learns: one daily loop

Every day the agent sees the shop, picks orders, and is scored on that day’s profit.
Environment

The simulated shop

  • 10 products, 3 suppliers, shared 20,000-unit warehouse
  • Random customers, delays, partial shipments, outages
  • Crises added from the LLM generator
  • 180 days per episode, first 14 not scored
What it sees →88 numbers: stock, stock on the way, days of cover, recent demand, season, supplier status
← What it doesper product: 1 of 21 options
(7 quantity levels × 3 suppliers)
← Scorethat day’s profit
Agent

RL agent (MaskablePPO)

  • Small neural network; trains on a normal computer (CPU)
  • Trained for 2 million steps
  • Quantity and supplier chosen together: 2.8× faster to train
Masking: impossible choices (an offline supplier, an order too big for the warehouse) are blocked before the agent chooses. Worth about 3×.
