SupplyAI-RL: system architecture

Data builds a simulator. Two decision makers act in it. An LLM layer explains and stress-tests. A dashboard shows everything.
1 Data

UCI Online Retail II

  • 1,067,371 real sales records
  • UK gift shop, 2009–2011
  • Cleaned, 10 products chosen to cover 3 demand types

Calibration

Five measurements only: mean demand, variability, weekday pattern, month pattern, zero-sales days.

➜
2 Simulator

Virtual shop (Gymnasium)

  • 10 products, 3 suppliers
  • One shared warehouse, 20,000 units
  • 180 days, 14-day warm-up
  • Random delays, partial shipments, outages

Daily cycle

deliveries → customers → sales → today’s orders → profit

3 Engine

Tuned classical policies

forecast + safety stocknewsvendorEOQ + ROP(s, S)

3 Challenger

MaskablePPO agent

  • 88 inputs, 21 options per product
  • Action masking blocks illegal choices
  • Scored, never in charge

  • Template if a number is invented

  • Spikes, outages, delays, cost jumps
